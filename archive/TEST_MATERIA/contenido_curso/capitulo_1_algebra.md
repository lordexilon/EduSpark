# 📐 Capítulo 1: Álgebra Básica

## 1.1 Introducción al Álgebra

El álgebra es una rama de las matemáticas que utiliza símbolos y letras para representar números y cantidades en fórmulas y ecuaciones. Es fundamental para resolver problemas matemáticos de manera sistemática.

### Conceptos Básicos

**Variable**: Una letra que representa un número desconocido. Ejemplos: x, y, z
**Constante**: Un número que no cambia. Ejemplos: 5, -3, 0.5
**Expresión algebraica**: Una combinación de variables, constantes y operaciones matemáticas.

### Ejemplos de Expresiones Algebraicas

- 3x + 5
- 2y - 7
- x² + 4x - 3
- 5a + 2b - c

## 1.2 Ecuaciones Lineales

Una ecuación lineal es una ecuación donde la variable tiene exponente 1.

### Forma General
ax + b = c

Donde:
- a ≠ 0 (coeficiente de x)
- b y c son constantes
- x es la variable

### Ejemplos de Ecuaciones Lineales

1. 2x + 3 = 11
2. 5y - 7 = 18
3. 3x = 15
4. x + 4 = 0

### Método de Resolución

Para resolver una ecuación lineal:

1. **Aislar la variable**: Usar operaciones inversas
2. **Simplificar**: Reducir términos semejantes
3. **Verificar**: Sustituir la solución en la ecuación original

### Ejemplo Resuelto

Resolver: 2x + 3 = 11

**Paso 1**: Restar 3 a ambos lados
2x + 3 - 3 = 11 - 3
2x = 8

**Paso 2**: Dividir por 2
2x ÷ 2 = 8 ÷ 2
x = 4

**Verificación**: 2(4) + 3 = 8 + 3 = 11 ✅

## 1.3 Sistemas de Ecuaciones

Un sistema de ecuaciones es un conjunto de dos o más ecuaciones con las mismas variables.

### Método de Sustitución

1. Despejar una variable en una ecuación
2. Sustituir en la otra ecuación
3. Resolver para la variable restante
4. Encontrar la otra variable

### Ejemplo

Resolver el sistema:
```
x + y = 5
2x - y = 1
```

**Solución**:
De la primera ecuación: y = 5 - x
Sustituyendo en la segunda: 2x - (5 - x) = 1
2x - 5 + x = 1
3x - 5 = 1
3x = 6
x = 2

Sustituyendo x = 2 en y = 5 - x:
y = 5 - 2 = 3

**Solución**: x = 2, y = 3

## 1.4 Factorización

La factorización es el proceso de escribir una expresión como producto de factores.

### Factor Común

Sacar el factor común de todos los términos.

**Ejemplo**: 6x + 9 = 3(2x + 3)

### Diferencia de Cuadrados

a² - b² = (a + b)(a - b)

**Ejemplo**: x² - 16 = (x + 4)(x - 4)

### Trinomio Cuadrado Perfecto

a² + 2ab + b² = (a + b)²
a² - 2ab + b² = (a - b)²

**Ejemplo**: x² + 6x + 9 = (x + 3)²

## 1.5 Problemas de Aplicación

### Problemas de Edades

**Ejemplo**: La edad de Juan es el doble de la edad de María. Si la suma de sus edades es 36 años, ¿cuáles son sus edades?

**Solución**:
- Sea x = edad de María
- Entonces 2x = edad de Juan
- Ecuación: x + 2x = 36
- 3x = 36
- x = 12
- María tiene 12 años, Juan tiene 24 años

### Problemas de Distancia, Velocidad y Tiempo

**Fórmula**: d = v × t

**Ejemplo**: Un automóvil viaja a 60 km/h durante 2.5 horas. ¿Qué distancia recorre?

**Solución**:
d = v × t
d = 60 × 2.5 = 150 km
