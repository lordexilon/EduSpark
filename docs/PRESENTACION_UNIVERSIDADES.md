## 🎯 ¿Qué es EduSpark?

EduSpark es una **plataforma educativa integral** potenciada por **Inteligencia Artificial** diseñada específicamente para instituciones de educación superior en Paraguay.

### Stack Tecnológico
- **Frontend:** React + TypeScript + Vite (Aplicación Web Progresiva)
- **Backend:** Supabase + Firebase (Escalabilidad garantizada)
- **IA:** Google Gemini (Última generación)
- **Procesamiento:** RAG (Retrieval-Augmented Generation) para documentos

## 📚 Funcionalidades Principales

### 1. Generador de Flashcards con IA 🃏

```
📄 PDF de Anatomía → 🤖 Gemini IA → 🃏 50+ Flashcards en segundos
```

- **Extracción inteligente** de conceptos clave
- **Múltiples formatos:** Opción múltiple, Verdadero/Falso, Respuesta corta
- **Tags automáticos** por tema y dificultad
- **Procesamiento local** (privacidad garantizada)

### 2. Sistema de Evaluación Configurable 📝

| Escala | Configuración |
|--------|---------------|
| **1-5** | Universidad Católica style (60% mínimo) |
| **1-10** | Otras universidades (aprobación desde 5) |
| **Porcentual** | Flexible según reglamento interno |

**Tipos de evaluación soportados:**
- ✔️ Exámenes parciales
- ✔️ Trabajos prácticos
- ✔️ Exámenes finales
- ✔️ Evaluación continua
- ✔️ Rúbricas personalizadas

### 3. Planificación Académica 📅

- **Calendario académico** integrado
- **Mallas curriculares** por carrera y año
- **Seguimiento de competencias** (enfoque MEC)
- **PEI/PCI digital** para acreditaciones

### 4. Gestión Docente 👨‍🏫

- Perfiles docentes con matrículas y títulos
- Asignación de materias y secciones
- Tracking de formación continua
- Comunicación integrada con estudiantes

### 5. Analytics y Reportes con Coach IA 📊

- **Tutor IA Proactivo**: El sistema analiza el progreso y riesgo del alumno antes de saludar, actuando como un Coach académico.
- **Análisis Semanal Consolidado**: Reportes pedagógicos profundos generados cada viernes para optimizar el aprendizaje y reducir costos de IA.
- **Métricas de Rendimiento**: Dashboards en tiempo real por carrera y curso.
- **Alertas Tempranas**: Detección automática de estudiantes en riesgo basada en interacciones y calificaciones.

### 6. Control de Costos y Sostenibilidad (Token Faucet) 💸

- **Grifo de Tokens**: Control administrativo total sobre el presupuesto de IA (Límites diarios globales y por usuario).
- **Hard Stop de Emergencia**: Capacidad de pausar servicios de IA instantáneamente.
- **Eficiencia de Tokens**: Arquitectura optimizada que prioriza el análisis semanal para maximizar el ROI educativo.

### 7. Certificación Automática de Logros 🎓

- **Certificados Digitales**: Emisión automática de diplomas en PDF al completar el 100% de los requisitos del curso.
- **Seguridad Académica**: Códigos de verificación únicos y registros en base de datos para validación institucional.
- **Reconocimiento Inmediato**: Incrementa la motivación del estudiante mediante recompensas digitales profesionales.
