### 1.2 Conceptos Fundamentales del Álgebra

#### Definición del Álgebra
El álgebra es una rama de las matemáticas que utiliza símbolos y letras para representar números y cantidades en fórmulas y ecuaciones. En el contexto empresarial, el álgebra permite modelar situaciones reales de manera abstracta y resolver problemas complejos de manera sistemática.

#### Elementos Básicos
- **Variable**: Una letra que representa un número desconocido o que puede variar
  - Ejemplos: x, y, z (variables independientes)
  - En contextos empresariales: precio (p), cantidad (q), tiempo (t)

- **Constante**: Un número que no cambia
  - Ejemplos: 5, -3, 0.5, π
  - En contextos empresariales: costos fijos, tasas de interés

- **Coeficiente**: El número que multiplica a una variable
  - Ejemplo: En 3x, el coeficiente es 3
  - En contextos empresariales: tasa de crecimiento, margen de ganancia

#### Expresiones Algebraicas
Una expresión algebraica es una combinación de variables, constantes y operaciones matemáticas.

**Ejemplos básicos:**
- 3x + 5 (expresión lineal)
- 2x² - 4x + 1 (expresión cuadrática)
- 5a + 2b - c (expresión con múltiples variables)

**Ejemplos empresariales:**
- Ingresos: I = px (precio por cantidad)
- Costos: C = 1000 + 50x (costo fijo + costo variable)
- Utilidades: U = I - C = px - (1000 + 50x)

### 1.3 Operaciones Básicas con Expresiones Algebraicas

#### 1.3.1 Suma y Resta
Para sumar o restar expresiones algebraicas, se combinan términos semejantes.

**Términos semejantes**: Términos que tienen las mismas variables con los mismos exponentes.

**Ejemplos:**
- 3x + 5x = 8x
- 2x² - 4x² = -2x²
- 3x + 2y + 5x - y = 8x + y

**Aplicación empresarial:**
Si una empresa tiene costos de:
- Materiales: 3x (donde x es la cantidad de productos)
- Mano de obra: 2x + 100
- Total de costos: 3x + (2x + 100) = 5x + 100

#### 1.3.2 Multiplicación
La multiplicación de expresiones algebraicas sigue las leyes de los exponentes y la propiedad distributiva.

**Leyes de exponentes:**
- xᵃ × xᵇ = xᵃ⁺ᵇ
- (xᵃ)ᵇ = xᵃᵇ
- x⁰ = 1

**Propiedad distributiva:**
a(b + c) = ab + ac

**Ejemplos:**
- 3x(2x + 5) = 6x² + 15x
- (x + 2)(x + 3) = x² + 3x + 2x + 6 = x² + 5x + 6

**Aplicación empresarial:**
Si una empresa vende x productos a un precio de (10 + 0.5x) cada uno:
Ingresos = x(10 + 0.5x) = 10x + 0.5x²

#### 1.3.3 División
La división de expresiones algebraicas puede resultar en expresiones fraccionarias.

**Ejemplos:**
- (6x² + 9x) ÷ 3x = 2x + 3
- (x² - 4) ÷ (x - 2) = x + 2

#### 1.3.4 Potenciación
La potenciación sigue reglas específicas:

**Ejemplos:**
- (2x)³ = 8x³
- (x + 2)² = x² + 4x + 4 (cuadrado de un binomio)

#### 1.3.5 Radicación
La radicación es la operación inversa de la potenciación:

**Ejemplos:**
- √(9x²) = 3|x|
- ∛(8x³) = 2x

### 1.4 Descomposición Factorial

#### 1.4.1 Factor Común
Sacar el factor común de todos los términos.

**Ejemplo básico:**
6x + 9 = 3(2x + 3)

**Ejemplo empresarial:**
Si los costos totales son 50x + 1000, el factor común es 50:
50x + 1000 = 50(x + 20)

#### 1.4.2 Diferencia de Cuadrados
a² - b² = (a + b)(a - b)

**Ejemplo:**
x² - 16 = (x + 4)(x - 4)

#### 1.4.3 Trinomio Cuadrado Perfecto
a² + 2ab + b² = (a + b)²
a² - 2ab + b² = (a - b)²

**Ejemplos:**
- x² + 6x + 9 = (x + 3)²
- x² - 8x + 16 = (x - 4)²

#### 1.4.4 Factorización de Trinomios
Para factorizar x² + bx + c, buscar dos números que sumen b y multipliquen c.

**Ejemplo:**
x² + 5x + 6 = (x + 2)(x + 3)
Porque: 2 + 3 = 5 y 2 × 3 = 6

### 1.5 Expresiones Algebraicas Fraccionarias

#### 1.5.1 Simplificación
Simplificar expresiones fraccionarias factorizando numerador y denominador.

**Ejemplo:**
(x² - 4)/(x² + 4x + 4) = (x - 2)(x + 2)/(x + 2)² = (x - 2)/(x + 2)

#### 1.5.2 Operaciones con Fracciones Algebraicas

**Suma y Resta:**
Encontrar el común denominador y operar.

**Ejemplo:**
1/(x + 1) + 2/(x - 1) = (x - 1 + 2(x + 1))/((x + 1)(x - 1))
= (x - 1 + 2x + 2)/(x² - 1) = (3x + 1)/(x² - 1)

**Multiplicación:**
Multiplicar numeradores y denominadores, luego simplificar.

**Ejemplo:**
(x + 1)/(x - 1) × (x - 1)/(x + 2) = (x + 1)(x - 1)/((x - 1)(x + 2))
= (x² - 1)/((x - 1)(x + 2)) = (x + 1)/(x + 2)

**División:**
Multiplicar por el recíproco.

**Ejemplo:**
(x + 1)/(x - 1) ÷ (x + 2)/(x - 1) = (x + 1)/(x - 1) × (x - 1)/(x + 2)
= (x + 1)/(x + 2)

### 1.6 Aplicaciones Empresariales

#### 1.6.1 Modelo de Costos
Una empresa tiene costos fijos de $1000 y costos variables de $50 por unidad producida.
- Costo total: C(x) = 1000 + 50x
- Si produce 20 unidades: C(20) = 1000 + 50(20) = 2000

#### 1.6.2 Modelo de Ingresos
La empresa vende cada unidad a $80.
- Ingresos: I(x) = 80x
- Si vende 20 unidades: I(20) = 80(20) = 1600

#### 1.6.3 Modelo de Utilidades
Utilidad = Ingresos - Costos
- U(x) = I(x) - C(x) = 80x - (1000 + 50x) = 30x - 1000
- Si vende 20 unidades: U(20) = 30(20) - 1000 = -400 (pérdida)

#### 1.6.4 Punto de Equilibrio
Para encontrar el punto de equilibrio, hacer U(x) = 0:
30x - 1000 = 0
30x = 1000
x = 1000/30 ≈ 33.33 unidades

### 1.7 Ejercicios de Aplicación

#### Ejercicio 1: Análisis de Costos
Una empresa tiene la siguiente estructura de costos:
- Costos fijos: $5000
- Costos variables: $25x + 0.1x²

Expresar el costo total como una expresión algebraica y calcular el costo para 100 unidades.

**Solución:**
C(x) = 5000 + 25x + 0.1x²
C(100) = 5000 + 25(100) + 0.1(100)²
C(100) = 5000 + 2500 + 1000 = 8500

#### Ejercicio 2: Optimización de Producción
Una empresa puede producir x unidades con un costo de C(x) = x² - 10x + 100.
Encuentre la expresión factorizada del costo.

**Solución:**
C(x) = x² - 10x + 100
Completando el cuadrado: C(x) = (x - 5)² + 75
