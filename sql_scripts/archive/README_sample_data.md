# Datos de Ejemplo para EduSpark

## 🚀 Cómo Agregar Cursos de Ejemplo

### Opción 1: Script Automático (Recomendado)
1. Ve a la consola de Supabase
2. Navega a **SQL Editor**
3. Copia y pega todo el contenido de `insert_sample_data.sql`
4. Haz clic en **"Run"**
5. ¡Listo! Tendrás 3 cursos completos con contenido

### Opción 2: Script Manual
1. Ejecuta primero `create_sample_courses.sql`
2. Luego ejecuta `sample_data.sql` (reemplazando los IDs)

## 📚 Cursos de Ejemplo Incluidos

### 1. **Python para Principiantes** (PYTHON101)
- **5 unidades**: Desde instalación hasta POO básica

- **2 tareas**: Ejercicios de variables, calculadora simple

### 2. **React y JavaScript Moderno** (REACT201)
- **5 unidades**: Desde conceptos básicos hasta routing
- **1 material**: Documentación oficial de React
- **1 tarea**: Componente de tarjeta reutilizable

### 3. **Machine Learning Básico** (ML301)
- **5 unidades**: Desde conceptos básicos hasta evaluación
- **1 tarea**: Análisis exploratorio de datos
